# Hệ thống quản lý sinh viên – Student Management

Dự án website quản lý sinh viên được tôi sử dụng để học tập và thực hành lập trình Backend với ASP.NET Core MVC, REST API và SQL Server.

## Giới thiệu

Hệ thống hỗ trợ quản lý thông tin sinh viên, thực hiện các thao tác thêm, xem, chỉnh sửa, xóa, tìm kiếm và thống kê dữ liệu.

Dự án đang được tôi tìm hiểu, Việt hóa giao diện và phát triển thêm các chức năng để nâng cao kỹ năng lập trình .NET.

## Công nghệ sử dụng

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- RESTful API
- Swagger
- Bootstrap 5

## Chức năng chính

- Quản lý danh sách sinh viên
- Thêm và cập nhật thông tin
- Xóa sinh viên
- Tìm kiếm và phân trang
- Thống kê dữ liệu trên Dashboard
- Kiểm thử API thông qua Swagger

## Định hướng phát triển

- Hoàn thiện giao diện tiếng Việt
- Nâng cấp dự án lên .NET 10
- Bổ sung đăng nhập và phân quyền
- Quản lý lớp học và ngành đào tạo
- Cải thiện chức năng tìm kiếm và báo cáo thống kê

## Nguồn tham khảo

Dự án được phát triển phục vụ mục đích học tập, dựa trên mã nguồn tham khảo [SOFTDEV-CRUD](https://github.com/apcjomaala1/SOFTDEV-CRUD). Các phần Việt hóa, chỉnh sửa và chức năng mới sẽ được cập nhật trong quá trình phát triển.
